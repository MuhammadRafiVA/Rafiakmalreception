PUBLISH
1. Create a PUBLIC GitHub repository.
2. Upload index.html and the entire assets folder (keep the folder name "assets").
3. Open repository Settings > Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait for GitHub Pages to publish the site.

OPTIONAL MUSIC
Add your own permitted MP3 file named wedding-music.mp3 inside the assets folder.
The music button will then play/pause it after a visitor taps it.
